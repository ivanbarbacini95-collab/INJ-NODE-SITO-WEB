# INJ NODE — Public Site
Sito statico pronto per GitHub Pages.

## Pubblicazione
1. Crea un nuovo repository GitHub.
2. Carica i file contenuti nello ZIP nella root del repository.
3. Settings → Pages → Deploy from a branch → main / root.

## Dati capitale
Per la demo i valori pubblici sono in `app.js` nella costante `PUBLIC`.
Il pulsante “Apri INJ NODE” punta alla piattaforma INJ NODE esistente.
