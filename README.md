# INJ NODE Public Website v2
Sito pubblico statico pronto per GitHub Pages.

Il capitale gestito viene calcolato live interrogando i 5 account Treasury già presenti in INJ NODE. Gli indirizzi sono usati dal browser per leggere dati pubblici on-chain ma non vengono mostrati nell'interfaccia.

Carica tutti i file e la cartella assets nella root del repository, poi abilita GitHub Pages.
